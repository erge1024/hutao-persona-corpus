## 1. 模板结构说明（任务 A，已确认）

API：`action=parse&page=<页面名>&prop=wikitext&format=json&formatversion=2`

### 1.1 角色台词
```
*派蒙：为、为什么我们要到这里来？我有一种很不好的预感。
*胡桃：我是胡桃，往生堂的当代堂主，具体掌管的…嗯，就是些生离死别的小事。
```
- 行首单个 `*`，`角色名：台词`，全角冒号。
- 多行台词用 `<br>` 分隔，解析时按 `<br>` 拆行逐行判断。
- 链接语法 `[[胡桃]]` / `[[胡桃|胡桃]]` 已剥离为纯文本（取 `|` 后显示名）。

### 1.2 旁白
```
{{任务描述|这天晚上，你在睡梦中听见一个熟悉的声音…|璃月 无妄坡}}
```
- 参数 1 = 旁白正文，参数 2 = 地点。
- 纯文本旁白仅在 `==任务剧情==` 之后的小节内判定（不以「角色名：」开头的非列表段落）。

### 1.3 玩家选项
```
{{剧情选项
|选项1=我是旅行者。
|剧情1=老孟：旅、旅行者？难道是外国人？不对，没见过这样的打扮。<br>
老孟：难道说，是、是从「那个世界」旅行来的？！
|选项2=我是天外来客。
|剧情2=老孟：天外来客？这种说法太古怪了…<br>
老孟：别、别吓唬人了！}}
```
- `选项N` = 玩家选项文本；`剧情N` = 该分支的台词/旁白序列，按 `<br>` 拆行后逐行判断是台词还是旁白。
- 仅有选项、无分支时只有 `选项N` 参数。

### 1.4 噪声模板（不参与对话提取）
`{{任务}}` 信息框、`{{折叠}}`、`{{颜色}}`、`{{图标|…}}`。

### 1.5 解析器边界处理（按确认的 5 条规则）
1. 两种链接语法均剥离；旁白/选项内嵌链接同样剥离。
2. `剧情N` 先按 `<br>` 拆行，再逐行判台词/旁白（不假设全是台词）。
3. 单 `*` 为主对话行；`**` 行按同规则解析（本批数据中未出现需要归属异常的 `**` 行）；空行/模板行不静默丢弃，统一进入 item 序列。
4. 纯文本旁白判定只在 `==任务剧情==` 之后生效。
5. 全角冒号优先取**最后一个**作分隔，并校验说话人前缀（长度 ≤20、不含句读符号），校验失败回退第一个冒号；仍失败判为旁白，避免静默错切。
